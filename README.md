# bazi-analyzer

> 八字（四柱）分析工具：公历/农历与干支纪法转换、在线排盘与分析。

## 简介

**bazi-analyzer** 是一款基于 **Vite + TypeScript** 的八字排盘分析工具：支持公历/农历日期换算、验证，并对四柱八字进行分析。

## 功能

- 📅 公历 ↔ 农历（干支纪法）换算
- 🧮 八字（年柱/月柱/日柱/时柱）排盘
- ✅ 内置验证脚本（`verify-lunar.ts`、`verify.ts`）校验历法计算

## 快速开始

```bash
npm install
npm run dev
```

| 命令 | 说明 |
|------|------|
| `npm run dev` | 开发预览 |
| `npm run build` | 构建生产产物 |
| `npm run preview` | 预览构建产物 |
